ShikshaGap — Technical Blueprint

Pure-function diagnostic engine, decision table, 9 sequence tests, longest path, and mathematical data validation.

🛡️ The Anti-Faking Architecture

The engine is pure: no React, no DOM, no Math.random(), no Date.now(). The rng: () => number is a required parameter. Tests choose answers via semantic answerCorrectly(state) and answerWrongly(state) helpers—never option letters, positions, or hardcoded IDs.

How Tests Answer

Tests never hardcode option letters ('A'..'D') or indices. They use semantic helpers: 

export function answerCorrectly(state: EngineState): string {
  if (!state.currentQuestion) throw new Error("No active question to answer");
  const correct = state.currentQuestion.options.find(o => o.isCorrect);
  if (!correct) throw new Error("Question has no correct option marked");
  return correct.id;
}

export function answerWrongly(state: EngineState): string {
  if (!state.currentQuestion) throw new Error("No active question to answer");
  const wrong = state.currentQuestion.options.find(o => !o.isCorrect);
  if (!wrong) throw new Error("Question has no wrong options");
  return wrong.id;
}
